# requirements-lock.txt — pipeline dependencies (CPU and GPU installs)
#
# Install order (what gui/packaging/setup_runtime.cmd does):
#   1. pip install -r requirements-lock.txt
#   2. pip install --no-deps -r requirements-paddle-cpu.txt   (or -gpu)
#
# Why two steps: paddlepaddle 2.6.2 declares protobuf<=3.20.2 on Windows, but
# google-genai needs protobuf 5.x.  pip cannot resolve both in one install
# (ResolutionImpossible), so Paddle is installed with --no-deps; its other
# dependencies (httpx, numpy, Pillow, decorator, astor, opt-einsum) are pinned
# here.  At runtime the conflict is harmless because
# PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python is set in verify_colleges.py.
#
# Python 3.12 only: paddlepaddle 2.6.2 and numpy 1.26 have no Python 3.13
# wheels.  The installer ships its own Python 3.12 runtime.
#
# Direct dependencies:
#   verify_colleges.py    -> pandas, playwright, beautifulsoup4, tqdm, python-dotenv
#   document_processor.py -> PyMuPDF, opencv-python, Pillow
#   extractor.py          -> ollama
#   ocr_engine.py         -> paddlepaddle (separate file), paddleocr<3.0, tqdm
#   web_resolver.py       -> google-genai, rapidfuzz, python-dotenv
#   scoring.py            -> rapidfuzz
#
# The GUI's own dependencies are in gui/requirements.txt (not needed here).
